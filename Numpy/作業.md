# 作業 求以下的執行結果
```py
np.tile(np.array([[1,2],[6,7]]),3)
```
```
array([[1, 2, 1, 2, 1, 2],
       [6, 7, 6, 7, 6, 7]])
```
```py
np.tile(np.array([[1,2],[6,7]]),(2,2))
```
```
array([[1, 2, 1, 2],
       [6, 7, 6, 7],
       [1, 2, 1, 2],
       [6, 7, 6, 7]])
```
