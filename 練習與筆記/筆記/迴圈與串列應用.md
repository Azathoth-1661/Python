## 🔁 迴圈基礎語法

### 🔹 for 迴圈結構
```python
for i in range(5):
    print(i)
```

### 🔹 while 迴圈結構
```python
i = 0
while i < 5:
    print(i)
    i += 1
```

## 🧠 練習與挑戰

### 🔸 加總 1~100 的總和
```python
i_total = 0
for i in range(1, 101):
    i_total += i
print(i_total)
```

### 🔸 找出 1~99 間的 7 的倍數
```python
for i in range(1, 100):
    if i % 7 == 0:
        print(i)
```

## 🔁 while + break / continue 應用

### 🔸 密碼輸入直到正確
```python
password = "pass123"
while True:
    password_1 = input("請輸入密碼：")
    if password_1 == password:
        print("登入成功")
        break
    else:
        print("請輸入正確的密碼")
```

### 🔸 密碼三次輸入錯誤即鎖定
```python
password = "pass123"
attempts = 3
while True:
    input_pw = input("請輸入密碼：")
    if input_pw == password:
        print("密碼正確，登入成功！")
        break
    else:
        attempts -= 1
        if attempts > 0:
            print(f"密碼錯誤，你還剩下 {attempts} 次機會")
        else:
            print("帳號鎖定，請聯絡管理員。")
            break
```

## 🧩 額外挑戰題

### 🔸 倒扣挑戰：從 100 開始倒扣，每次扣掉遞增的數字直到負數
```python
score = 100
step = 1
while score > 0:
    score -= step
    step += 1
print(f"扣了 {step-1} 次後為負")
```

## ⭐ 巢狀迴圈圖形練習

### 🔸 左上三角形
```python
for i in range(1, 6):
    for j in range(i):
        print("★", end="")
    print("")
```

### 🔸 右上三角形
```python
for i in range(5):
    for j in range(i):
        print(" ", end="")
    for k in range(5 - i):
        print("★", end="")
    print("")
```

### 🔸 正三角形
```python
for i in range(5, 0, -1):
    for j in range(i):
        print(" ", end="")
    for k in range(6 - i):
        print("★", end="")
    print("")
```

### 🔸 九九乘法表
```python
for i in range(1, 10):
    for j in range(1, 10):
        print(f"{j}*{i}={j*i:<2}", end="\t")
    print("")
```

## 📋 串列基本應用

### 🔸 建立與輸出
```python
fruits = ["apple", "banana", "cherry"]
print(fruits)
print(fruits[0])
```

### 🔸 透過 for 搭配 index 輸出
```python
for i in range(len(fruits)):
    print(i, fruits[i])
```

### 🔸 新增與輸入元素
```python
fruits = []
count = 0
while count < 3:
    fruits.append(input("請輸入水果名稱"))
    count += 1
print(fruits)
```

### 🔸 使用 in 判斷元素是否存在
```python
if "apple" in fruits:
    print("有 apple")
```
