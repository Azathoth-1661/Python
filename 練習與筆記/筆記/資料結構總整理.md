
# 📊 Python 資料結構總整理（List / Dict / List+Dict）

---

## 🧱 1. List（串列）

📌 串列是有順序的可變動容器，使用 [] 包裹。

```python
fruits = ["apple", "banana", "cherry"]
```

🔸 特性：
- 有順序，可透過索引存取。
- 可包含任意型別（數字、字串、布林、甚至其他串列）。
- 可變動（mutable）。

🔧 常見操作：
| 操作        | 範例                           |
|-------------|--------------------------------|
| 取值        | fruits[0] → "apple"           |
| 加入元素    | fruits.append("mango")         |
| 插入元素    | fruits.insert(1, "kiwi")       |
| 移除元素    | fruits.remove("banana")        |
| 刪除指定索引| del fruits[0]                 |
| 串列長度    | len(fruits)                    |
| 清空串列    | fruits.clear()                 |

🧠 練習題：輸入 3 種水果並顯示
```python
fruits = []
while len(fruits) < 3:
    fruits.append(input("請輸入水果名稱："))
print(fruits)
```

## 🗂 2. Dict（字典）

📌 字典是 key:value 配對的集合，使用 {} 包裹。

```python
person = {
    "name": "Amy",
    "email": "amy@gmail.com",
    "phone": "0988-xxxxxx"
}
```

🔸 特性：
- 沒有順序（Python 3.7+ 開始插入順序會保留）。
- 以 key 存取資料。
- Key 必須唯一，通常是字串或數字。

🔧 常見操作：
| 操作        | 範例                                   |
|-------------|----------------------------------------|
| 存取        | person["name"] → "Amy"                |
| 新增        | person["birthday"] = "0728"            |
| 修改        | person["email"] = "new@email.com"      |
| 刪除        | del person["phone"]                    |
| 是否存在    | if "email" in person: ...              |
| 取所有項目  | for key, value in person.items(): ...  |

🧠 小挑戰：驗證 email 欄位
```python
if "email" in person and "@" in person["email"]:
    print("合法 email")
else:
    print("格式不正確")
```

## 🧩 3. List + Dict 混合（學生資料）

📌 最常見的資料格式為「多筆字典組成的串列」，如：

```python
students = [
    {"id": "001", "name": "Amy", "score": 85},
    {"id": "002", "name": "Bob", "score": 77},
    {"id": "003", "name": "Charlie", "score": 92}
]
```

📊 圖解結構：

students → List  
  ├── dict → {"id": ..., "name": ..., "score": ...}  
  ├── dict → {...}  
  └── dict → {...}

🔁 常見迴圈：
```python
for student in students:
    print(student["id"], student["name"], student["score"])
```

## 🧪 挑戰應用整理

### ✅ 資料篩選與分類

🔹 找出 80 分以上的學生：
```python
high_scores = []
for student in students:
    if student["score"] > 80:
        high_scores.append(student)
```

🔹 分類及格與不及格學生：
```python
pass_students = []
fail_students = []
for student in students:
    if student["score"] >= 60:
        pass_students.append(student)
    else:
        fail_students.append(student)
```

🔹 計算總分與平均：
```python
total_score = sum([s["score"] for s in pass_students])
average = total_score / len(pass_students)
```

---

### 🥇 找出最高分與最低分

```python
max_score = -1
top_student = None
for s in students:
    if s["score"] > max_score:
        max_score = s["score"]
        top_student = s
```

```python
min_score = 101
low_student = None
for s in students:
    if s["score"] < min_score:
        min_score = s["score"]
        low_student = s
```

### 🎯 區間統計（60~89 / >=90）

```python
students_90 = []
students_6089 = []
students_60 = []

for s in students:
    if s["score"] >= 90:
        students_90.append(s)
    elif 60 <= s["score"] < 90:
        students_6089.append(s)
    else:
        students_60.append(s)
```

### 🧾 學生資訊查詢 / 更新 / 刪除（含防呆）

✔ 查詢學號：
```python
id_input = input("請輸入學號：")
if id_input.strip() == "":
    print("請輸入有效學號")
else:
    for s in students:
        if s["id"] == id_input:
            print(s["name"], s["score"])
            break
    else:
        print("查無此學號")
```

✔ 更新分數：
```python
# 加上 strip() 與 int 轉換防呆
if s["id"] == id_input:
    new_score = int(input("請輸入新分數："))
    s["score"] = new_score
```

✔ 刪除學生：
```python
students.remove(student)
```

## 📌 資料型別快速判斷技巧

```python
print(type(data))  # <class 'list'> or <class 'dict'>
```

---

📝 整合說明：

- 使用 type() 或 print 檢查資料結構
- 如果資料是一筆筆的物件集合，通常會是 List + Dict 結構
- 請記得：
  - List 適合處理「多筆資料」
  - Dict 適合描述「單筆資料的欄位」
  - 混用結構是實務常見模式
