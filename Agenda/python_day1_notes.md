## 📘 重點語法整理

```python
# 整數 int
age = 25

# 浮點數 float
height = 170.5

# 字串 str
name = "宗彥"

# 布林值 bool
is_tired = False

# 顯示資料型態
print(type(age))        # <class 'int'>
print(type(name))       # <class 'str'>
```

```python
# 使用 input() 輸入資料（回傳為字串）
user_input = input("請輸入年齡：")
print("你輸入的是：" + user_input)
```
