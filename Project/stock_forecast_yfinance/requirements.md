套件需求清單

本專案使用以下 Python 套件，建議使用者於 Colab 或本地環境安裝相同版本以確保執行順利。

## 套件列表

| 套件名稱     | 用途說明                             |
|--------------|--------------------------------------|
| `pandas`     | 資料處理與技術指標計算               |
| `matplotlib` | 繪製折線圖、長條圖等視覺化成果       |
| `seaborn`    | 繪製 KDE 曲線與分佈圖                |
| `yfinance`   | 擷取台灣科技股歷史股價資料           |
